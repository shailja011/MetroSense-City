# MetroSense City — Security Policy

## Reporting a Vulnerability

Please do not disclose sensitive vulnerability details
through public GitHub issues.

Contact the project maintainers privately to report
a potential security vulnerability.

Include the following information:

- Affected feature or file
- Steps to reproduce the issue
- Potential impact
- Suggested mitigation, if available

## Security Principles

### 1. Secrets Management
API keys, passwords, database credentials, and other
secrets must never be committed to the public repository.

### 2. Data Privacy
Only fictional demonstration data should be included
in the public repository.

### 3. Access Control
Protected operations should be accessible only to
authorized users.

### 4. Report Integrity
Approved reports should not be silently modified
or deleted.

### 5. Audit Trail
Audit records should be protected against unauthorized
alteration or deletion.

## Implementation Status

These principles describe the project's security goals.
Actual protections depend on the features implemented
and tested in the application.
