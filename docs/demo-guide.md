# MetroSense City — Demo Guide

## Project Overview

MetroSense City is designed to digitize inspection workflows
and simplify test-report generation for Non-Automatic
Weighing Instruments (NAWI).

## Demonstration Workflow

### 1. Open the Dashboard
Show the MetroSense City dashboard and explain its purpose.

### 2. Select an Instrument
Demonstrate instrument selection or registration, if available.

### 3. Start an Inspection
Open the inspection interface and show the available fields.

### 4. Enter Test Observations
Enter a reference load and the instrument's indicated value.

### 5. Calculate Measurement Error
Demonstrate the calculation:

E = I - L

Where:
- E = measurement error
- I = instrument indication
- L = applied reference load

### 6. Review Test Results
Show the calculated results and applicable acceptance limits,
if supported by the current implementation.

### 7. Generate a Test Report
Demonstrate report generation if available.

### 8. Verify the Report
Show QR-based verification if implemented.

### 9. Review Inspection History
Demonstrate stored inspection records and audit history,
if available.

## Demo Preparation Checklist

- Confirm the application loads correctly.
- Use fictional demonstration data.
- Test all features before presenting.
- Avoid displaying API keys or private information.
- Clearly distinguish working features from planned features.
